
# 霓虹方块

一个零依赖、打开即玩的浏览器俄罗斯方块游戏。

## 运行

直接打开 `index.html`，或在项目目录启动任意静态文件服务器：

```bash
node dev-server.mjs
```

然后访问 `http://127.0.0.1:4173`。

## 操作

- `←` / `→`：左右移动
- `↑`：顺时针旋转
- `↓`：加速下落
- `空格`：直接落下
- `P`：暂停或继续

每消除 10 行提升一个等级，等级越高，下落速度越快。

## 测试

```bash
npm test
```

测试覆盖方块旋转、边界和堆叠碰撞、消行、计分、硬降、状态初始化、落地与游戏结束。
